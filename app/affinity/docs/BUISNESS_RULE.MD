# 친밀도 도메인 비즈니스 룰

## 레벨과 진행도

- 현재 레벨은 `affinity.level_id`로 연결된 레벨을 기준으로 판단한다.
- `current_xp`는 누적 친밀도 포인트이며 다음 레벨의 `level_xp`를 진행도 목표로 사용한다.
- 진행률은 `current_xp / 다음 레벨 level_xp * 100`의 소수점 이하를 버린 값이며 최대 100으로 제한한다.
- 다음 레벨까지 필요한 XP는 `다음 레벨 level_xp - current_xp`로 계산하며 최소 0으로 제한한다.
- 최고 레벨은 진행률 100, 남은 XP 0으로 처리한다.

## 레벨 보상

- 현재 및 다음 레벨 보상은 `reward_item.reward_level`에 설정된 레벨을 기준으로 구성한다.
- `reward_level`이 `null`인 미션 보상은 레벨 보상에 포함하지 않는다.
- `reward_level` 값은 실제로 존재하는 `level.level`이어야 하며 보상 등록 또는 변경 시 검증한다.
- 삭제된 보상 아이템은 제공하지 않는다.

## 데일리 활동

- 활성 상태이고 삭제되지 않은 모든 `DAILY` 미션을 진행 여부와 관계없이 제공한다.
- 기간이 설정된 미션은 현재 시각이 시작일과 종료일 범위에 포함될 때만 제공한다.
- 진행 정보가 없는 미션은 진행 수 0, `IN_PROGRESS`, 보상 미수령 상태로 취급한다.
- 데일리 미션은 미션 id 오름차순으로 제공한다.
- 조회 과정에서는 미션 진행 정보 생성, 레벨 변경 또는 보상 지급을 수행하지 않는다.
