# 백엔드 API 구현 규칙

이 문서는 공모전 백엔드 API를 구현할 때 모든 작업자가 따라야 하는 고정 기준이다.

1. 우선순위가 `Must have`인 API만 먼저 구현한다.
2. 정상 응답 JSON의 값은 형식 예시일 수 있다. DB 모델이나 Enum에 값이 정의되어 있으면 실제 정의를 우선한다.
3. 로그인과 액세스 토큰은 구현하지 않는다. `users/me` API는 DB에 저장된 데모 사용자를 사용한다.
4. Swagger 실행에 데이터가 필요하면 응답을 하드코딩하지 않고 DB에 재실행 가능한 데모 데이터를 저장한다.
5. API마다 명시된 오류 응답을 실제 요청 구조와 대조한다. 필요 없는 오류, 누락된 오류, 공통 오류를 구현 결과와 함께 보고한다.
6. 구현을 마치면 추가·수정·삭제한 파일을 모두 보고한다.
7. 응답 스키마 테스트, 오류 응답 테스트, 실제 Docker DB 호출을 가능한 범위에서 검증한다.
