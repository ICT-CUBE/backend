- 현재 로그인 기능이 존재하지 않으므로 엑세스 토큰이 발급되지 않고, 사용자 검증이 불가하다. 따라서 서비스를 사용할 수 있는 대표 사용자가 (id = 1) 항상 존재한다고 가정하며 관련해서 404 에러를 보내지 않는다. ⇒ 현재까지 만들어진 소유권 관련 오류 응답은 삭제 예정.
    - 또한 id가 1인 유저는 ACTIVE 상태의 제니 큐브 앨범 하나를 소유중이라고 가정한다. 마찬가지로 소유권 관련 404나 403 에러를 반환하지 않는다.
- 시간 정보는 ISO 8601 형식에 offset을 붙인 한국 표준시를 사용한다. 예) 2026-08-12T17:20:00+09:00
- 400 에러는 **`INVALID_REQUEST`** 코드 하나로 통일해서 전송한다**.**
- 500 에러는 `INTERNAL_SERVER_ERROR` 코드 하나로 통일해서 전송한다.
- 400과 500 에러 응답은 각 api에 따로 명시하지 않는다.
- 현재 미션을 달성을 감지하고 counting하는 로직은 구현되어있지 않다.
- 현재 사용자 대화 발언에서 부적절성을 감지하고 block하는 로직은 구현되어있지 않다. 또한 block된 대화는 그대로 노출되고, 보관도 할 수 있음. 향후 수정 예정.
